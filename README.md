# DoctorTemplate — Medical Practice Website Theme

A modern, high-performance medical practice website template built with **Astro 5**, **Tailwind CSS v4**, and **Glassmorphic UI Design**. Modeled with clinical structure inspired by **Mayo Clinic** and interactive depth elevation inspired by **MudBlazor**.

---

## ✨ Features

- **Modern Frosted Glassmorphism**: Glass panels with specular rim lighting, top inner bevel highlights, and diffuse ambient light refraction.
- **MudBlazor-Style Elevation Hierarchy**: Layered depth box-shadow scale (`elevation-1` through `elevation-12`) with hover lift and ambient medical azure glow.
- **Dual Responsive Layout Architecture**: Every section features dedicated, cleanly separated Desktop (`hidden md:block`) and Mobile (`block md:hidden`) layouts.
- **Mayo Clinic Inspired Clinical Information**:
  - Floating pill glass navbar over cutout hero
  - QuickCare triage bar (Appointment, Treatments, Second Opinion, Telehealth)
  - 6 Clinical Specialties with diagnostic indicators
  - Doctor Credentials & Patient-First Care Pillars
  - 4-Step Patient Care Journey
  - Verified Clinical Outcomes & Patient Stories
  - Consultation Booking Form with in-clinic & telehealth support
  - Realistic Clinic Location with interactive **Google Maps** embed & transit connectivity
  - Patient FAQs & Comprehensive Medical Disclaimer

## 🚀 Getting Started

### Prerequisites
- Node.js `>= 22.12.0`

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
# or in background mode:
npx astro dev --background
```

### Production Build
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: [Astro 5](https://astro.build)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) via `@tailwindcss/vite`
